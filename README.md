## Open Source

I use open-source contribution as a production-engineering exercise: understand the issue, read the repository, make the smallest useful change, cover it with tests, pass CI, and iterate on maintainer feedback.

- **TealTiger** · [merged PR #34 — add `formatCost()`](https://github.com/agentguard-ai/tealtiger-typescript-prod/pull/34)  
  Added a public cost-formatting helper, covered zero-cost / single-request / pricing-gap cases, and verified CommonJS + ESM packaging.

- **OpenMed** · [merged PR #3079 — canonical governance identifiers](https://github.com/maziyarpanahi/openmed/pull/3079)  
  Added typed capability / purpose / policy / workflow / tool identifiers with strict canonical parsing, value-free diagnostics, documentation, and focused validation tests.

- **Ruflo** · [merged PR #3331 — fix doctor memory diagnostics](https://github.com/ruvnet/ruflo/pull/3331)  
  Removed a misleading table-count heuristic that reported fresh databases as stale, tightened diagnostic claims, and added regression coverage across initialization and failure paths.
